# Solana AI Trader

A cautious starter project for researching Solana tokens and testing strategies in **paper-trading mode**.

## Safety defaults
- Live trading is disabled and not implemented.
- Never commit wallet seed phrases, private keys, or API secrets.
- Store secrets only in a private server environment.
- Paper-trade and review performance before considering real funds.

## Setup
1. Install Python 3.11+.
2. Create and activate a virtual environment.
3. Install dependencies: `pip install -r requirements.txt`.
4. Copy `.env.example` to `.env`.
5. Run: `python main.py`.

This starter does not promise profits and does not place real orders.
